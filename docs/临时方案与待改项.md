## 1. 装备页转盘（`CSGORadialSelector` / `CSGOLoadout`）

> 剩余的轻微瑕疵**暂不修**，待办编号 `W1`（
> 详见 `docs/待办任务表.md`）。将来要修时把现象逐条列到这里再动手。

| 位置 | 临时做法 | 为什么 | 将来怎么改 |
|---|---|---|---|
| `csgo_loadout.cpp::FillWheelFromCatalog()` | ✅ 2026-09-20 已替换：从真数据 `se_faux_econ::GetSlotItem( subPosition, team )` 取槽位基础武器（真实名字 token + `econ/weapons/base_weapons/*.png` 剪影图标） | 原先本构建没有真 econ / 物品 schema | 仍需真 econ 后改成取"该槽**已装备**物品"（现在是槽位默认武器 + 阵营优先级；没有库存/磨损/贴纸状态） |
| `csgo_loadout.cpp::FillWheelFromCatalog()` | ✅ 2026-09-20 已替换：`equip_slot` = 真实槽位名（`secondary0..4` / `smg0..4` / `rifle0..5` / `heavy0..4`，来自 items_game 的 `item_sub_position`）；**点楔子会真正过滤物品列表** —— 目录 group 层 = 物品槽位，按前缀匹配（`rifle`→rifle0..5、`rifle1`→单格），并按当前阵营过滤（CT 视角 1085→298 条） | 原先只是名字、点哪个都一样 | 仍需真 econ 后按"**已装备**"筛选；目前筛的是"该槽位 + 该阵营可用的所有真物品" |
| `csgo_loadout.cpp::EnsureWheelReady()` | 四个入口反复重试（构造 / `OnInitializedFromLayout` / `EventShowLoadout` / `EventFilterForPosition`），并**主动去掉** `#LoadoutRadialSelector` 的 `hidden` class | 内容侧 `loadout.js` 本该自己展开容器；移植里加载顺序不总保证构造时楔子已存在（CS:GO 靠 `BLoadLayout` 同步建好子面板） | 若确认加载顺序稳定，可只留构造 + `OnInitializedFromLayout` 两处；容器展开那行可删 |

| `csgo_radial_selector.cpp::OnCapturedMouseMove()` | 扇区索引做了夹取保护（`nPanelIdx >= GetChildCount()` → 最后一个） | 移植加的保护，避免 360°/0° 边界上越界 | 保留（无害）；若发现边界行为与 CS:GO 不同再精调 |
| `csgo_radial_selector.cpp` | 悬停/点击音效走 `UISoundSystem()->PlaySound()`，最终落到移植的 sound op 回退路径（`SUPPORTS_AUDIO` 未定义） | 本移植的设备分支被编译掉，只有 `StartSoundEvent` 回退 | 接上真正的 UI 声音子系统（或给 `SUPPORTS_AUDIO` 补齐）后，这里不用改代码，只需复核音量/声像语义 |
| `csgo_loadout.cpp::UpdatePanelsForLoadout()` | 队伍 Logo 用 `{images}/icons/{t,ct}_logo.svg` 直接设图；`team` 属性只有 2/3 两个值 | 没有真 loadout 状态 | 保持即可；如内容改图名再同步 |
| `csgo_loadout.cpp::EventFilterForPosition()` | 切队伍时**联动不完整**：列表会按事件里的新 team 过滤，但转盘可能仍显示旧阵营的枪（`m_nTeam` 只在 `EventShowLoadout()` → `UpdatePanelsForLoadout()` 更新；只收到 `FilterForPosition` 时 `EnsureWheelReady()` 用的是旧 team） | 用户实测（2026-09-20）："切队伍时列表/转盘有部分不完整联动"；内容侧在切队伍时不一定重发 `ShowLoadout` | 在 `EventFilterForPosition()` 里先 `m_nTeam = nTeam` 再 `EnsureWheelReady()`（或给 `EnsureWheelReady(team)` 传参）；修完删掉本行（待办编号 `W2`） |
